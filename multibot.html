Mati

Built with Discord.js v14, multi-server architecture. From moderation to economy, giveaways to ticket systems — Mati does it all.

Systems

What Does Mati Offer?

Moderation & Protection

Ban, Unban, Kick, Timeout, Warning system, Bulk message delete, Channel lock, Slow mode, Nuke, ModLog, Anti-Link, Anti-Spam, Anti-Caps, Anti-Swear.

Economy & Gambling

Balance, Daily reward, Work, Heist, Transfer money, Bank, Shop, Inventory, Leaderboard, Slot machine, Coin flip and interactive Blackjack (21).

Level & XP System

XP from messages and voice activity, level card, progress bar, server leaderboard, level-up log channel and level role rewards.

Support Ticket System

Button-based ticket panel, automatic private channel creation, close, claim, TXT transcript export and channel deletion controls.

Giveaway System

Timed countdown, button-based entry, automatic winner selection, end giveaway, reroll and active giveaway list.

Temporary Voice Rooms

Joining a "Create Room" channel opens a private voice room. Gives a control panel (Lock, Hide, Limit, Rename). Auto-deletes when empty.

Server Backup

Backs up all channels, categories and roles with one command and restores them on demand. Includes backup list and detail view.

Fun & Mini Games

Button-based Tic-Tac-Toe, Minesweeper, Number Guess, Word Chain, Love meter, Magic 8-ball and more.

Server Setup Tools

Custom welcome & leave messages, auto-role on join, member counter channels, button role menus, full audit logs and invite tracker.

Commands

Slash (/) Commands

Command Category Description
/ban <user> Moderation Bans a user from the server.
/timeout <user> Moderation Mutes a user for a specified duration.
/purge <amount> Moderation Bulk deletes messages.
/warn <user> Moderation Issues a warning and logs it.
/giveaway-start Giveaway Starts a timed button-based giveaway.
/level Level Displays your current level card.
/leaderboard Level Shows the server XP leaderboard.
/backup-create Setup Backs up the entire server structure.
/tempvoice-setup Setup Sets up the temporary voice room system.
/ticket-setup Ticket Creates the support ticket panel.
/security Protection Manages anti-raid, anti-spam and channel/role protection.
/tictactoe <opponent> Fun Starts a two-player button Tic-Tac-Toe game.
Getting Started

How to Set Up

01

Invite Mati

Use the invite button above to add Mati to your server and approve the required permissions.

02

Adjust Role Order

In your server settings, drag the "Mati" role above the roles you want it to moderate.

03

Configure Systems

Run /tempvoice-setup, /ticket-setup, /welcome-set and other setup commands to configure the features you need.
